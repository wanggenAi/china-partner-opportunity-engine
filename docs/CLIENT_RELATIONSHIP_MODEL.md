# Client relationship model

A relationship may grow from trial → next task → recurring need → ongoing support → retainer → long-term China partner. This is a hypothesis, not a mandatory sales funnel.

Start with one narrow, verifiable task. Agree what success means and deliver the evidence. At handoff, ask what remains difficult; suggest a related next task only when the answer supports it. Use recurring supplier communication, sample coordination or local research to identify repeat needs. A retainer needs a client request, defined scope, capacity and approved terms.

Milestones require records: a real two-way exchange for REAL_CONVERSATION; confirmed current need and deliverable fit for QUALIFIED_LEAD; an interested reply for POSITIVE_REPLY; an actually issued approved quote for QUOTE; payment evidence for PAID_TASK; a second paid engagement for REPEAT_CUSTOMER; an explicit ongoing arrangement for LONG_TERM_PARTNER. Drafts, public comments by other providers and estimated revenue do not count.

Record each event locally with date, lead ID, source, human approval if required, outcome and next action. Public state contains anonymous counts only.
