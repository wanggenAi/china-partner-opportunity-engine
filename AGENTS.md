# Working instructions

Use this repository only: `wanggenAi/china-partner-opportunity-engine`, default branch `main`. Keep the official name China Partner Opportunity Engine.

## Privacy

Never commit real contacts, full founder profiles, client conversations or real lead intelligence. Store them in `.env.local` and `private/`. Public examples must be synthetic. Do not copy private values into logs, test fixtures or CI output. Stage explicit public paths and run `scripts/check_public.py` before every commit. Never force-push.

## Trust and communication

Represent a real China-side operator, local problem solver and research/execution partner. Do not invent company size, staff, factories, clients, revenue, brands, cases or qualifications. Use only relevant founder facts. Separate observed facts, inference and unknowns.

Write fluent, coherent prose. Remove repetition and generic self-praise. Every reply must respond to that person's actual problem, provide a useful observation and offer one small next step. Do not recycle the same introduction. Avoid unrelated resume details and contact dumps.

## Authorization and progress

Research, reversible local implementation and preparation are authorized. Ask before actual outreach, client quotes, payment, offline action or legal/regulatory judgments. An approval must cover the concrete action or exact draft; never mark a message sent because it was generated. Contacts appear only in a human-approved continuation with appropriate context and platform permission.

Read `TASK_STATE.md` and `state/recovery.json` first. Resume the local queue; do not expose it in public recovery files. Update state after material work. Measure conversations, qualified leads, positive replies, approved quotes, paid tasks, repeat customers and long-term partners honestly.

Keep output small, use targeted searches and low-cost investigation first. Prefer Chrome through browser-harness for required browser interaction. No subagents are required for this first release.
